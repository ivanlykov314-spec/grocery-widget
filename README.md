# Покупки: виджет со списком для Android

Виджет на весь рабочий стол. В нём товары по категориям, у каждого товара есть галочка.

- **Галочка стоит**: товар есть дома.
- **Галочки нет**: нужно купить (такой товар выделен красным).
- Кнопка **«Все · купить N» / «Купить: N»** на виджете переключает вид: весь список или только то, что нужно купить. Второй вид удобен в магазине.
- Кнопка **+** открывает маленькое окно поверх рабочего стола. В нём вписываете товар и выбираете или создаёте категорию. Можно добавлять товары подряд, не закрывая окно.
- Нажатие на «Покупки» открывает приложение. Там можно переименовать или удалить товары и категории.
- Список общий для двух телефонов. Галочка, поставленная на одном телефоне, через пару секунд появляется на другом.
- Если в магазине нет сети, галочки всё равно ставятся и отправятся, когда связь вернётся.

```
server/    сервер для Railway (Node.js + Postgres)
android/   приложение и виджет (Kotlin, Jetpack Glance)
.github/   GitHub Actions сам собирает APK
```

---

## Шаг 1. Сервер на Railway (≈5 минут)

1. Railway → **New Project → Deploy from GitHub repo** → выберите этот репозиторий.
2. Откройте созданный сервис → **Settings → Root Directory** → впишите `/server`.
3. В проекте нажмите **+ New → Database → PostgreSQL**.
4. Сервис → **Variables**, добавьте:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
   - `FAMILY_KEY` = придумайте длинный пароль, например `banan-moloko-2026-xyz`. Это ваш общий семейный ключ.
5. **Settings → Networking → Generate Domain**. Получится адрес вида `xxxx.up.railway.app`. Запишите его.
6. Откройте этот адрес в браузере. Должно появиться `Grocery widget server OK`.

Этого уже достаточно для работы: телефоны будут синхронизироваться раз в 15 минут и по кнопке ⟳.
Чтобы галочки появлялись на втором телефоне мгновенно, сделайте шаг 2.

## Шаг 2. Мгновенная синхронизация через Firebase (≈10 минут, бесплатно)

1. Откройте https://console.firebase.google.com → **Создать проект** (Google Analytics можно выключить).
2. Нажмите ⚙ → **Project settings → General**. Внизу нажмите **Add app → Android**:
   - Package name: `com.family.grocery`
   - Нажмите **Register app**. Файл google-services.json скачивать не нужно, жмите «Далее» до конца.
3. На той же странице General перепишите в Railway → Variables:
   - `FIREBASE_PROJECT_ID`: значение поля **Project ID**
   - `FIREBASE_API_KEY`: значение поля **Web API Key**
   - `FIREBASE_APP_ID`: **App ID** вашего Android-приложения (вида `1:1234567890:android:abc123...`)
4. Вкладка **Cloud Messaging** → **Sender ID** → в Railway как `FIREBASE_SENDER_ID`.
5. Вкладка **Service accounts → Generate new private key**. Скачается JSON-файл. Откройте его и
   вставьте **всё содержимое целиком** в Railway как переменную `FIREBASE_SERVICE_ACCOUNT`.
6. Railway перезапустит сервер. В логах должна появиться строка `Firebase push включены`.

Если телефоны уже были подключены до этого шага: в приложении нажмите ⋮ → «Отключиться от сервера» и подключитесь снова.

## Шаг 3. Установка на телефоны

1. После каждого изменения в папке `android/` GitHub сам собирает APK (вкладка **Actions**, около 5 минут).
2. Скачать последнюю версию на телефон можно по ссылке
   `https://github.com/<ваш-логин>/<репозиторий>/releases/latest/download/grocery-widget.apk`
   (если репозиторий приватный, нужно быть залогиненным в GitHub в браузере телефона).
3. Откройте скачанный файл и разрешите установку из этого источника.
4. Запустите приложение «Покупки». Впишите адрес сервера и семейный ключ. На телефоне жены впишите те же значения.
5. Долгое нажатие на пустом месте рабочего стола → **Виджеты → Покупки** → перетащите на экран и растяните на весь экран.

**Важно для Xiaomi / Huawei / Honor / некоторых Samsung.** В настройках приложения «Покупки» разрешите
**автозапуск** и выключите **экономию батареи** (режим «Без ограничений»). Иначе система может
не пропускать push-уведомления, и виджет будет обновляться только по кнопке ⟳.

Обновления ставятся поверх старой версии, данные не теряются.
